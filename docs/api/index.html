對接步驟

  1. 開啟試點看板。 試點店號 c030020（target milkshac030020）。
    看板網址： https://ultronservice.github.io/milksha-demo/?mode=cloud&store=c030020
  2. 送第一筆 POST。 URL：https://asia-east1-milksha-qms-dev.cloudfunctions.net/posReceiver。 試點店測試期間 signature 可不帶。 
    curl -sS -X POST 'https://asia-east1-milksha-qms-dev.cloudfunctions.net/posReceiver' \
  -H 'Content-Type: application/json' \
  -d '{"isEncrypt":false,"serviceSpecialData_Json":{"target":"milkshac030020","data":{"number_content":[{"source_type":"From_Store_Preparing","number":"1234"},{"source_type":"From_Store_OK","number":"5678"}],"newsTicker_content":[],"newsTickerSpeed":0}},"merchant_id":"Milksha","account":"c030020","timeStmp":"2026-10-14-15-30-00:0123","serviceSpecialData_Json_Md5Hash":"<MD5>","signature":""}'
  3. 檢查 Response。 HTTP 永遠 200。 isOK: true 表示 Request 已被受理並處理完畢（不代表上板）。 解析 information JSON 字串，以 isSuccess 判斷號碼是否顯示。
  4. 常見錯誤。 下列失敗皆為 isOK: true、內層 isSuccess: false（文案不變）。
