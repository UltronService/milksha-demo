# 負責人試用步驟（雲端模式）

本文件說明控制頁與看板如何用雲端同步。控制頁在電腦操作。看板在機上盒顯示。

## 試用前請準備

後端會提供三項資料。請由負責人保管。勿公開貼文。勿提交到 Git。

第一項是 Firebase 專案 ID。Firebase 是 Google 的雲端服務名稱。專案 ID 是該服務的專案代號。

第二項是 Web API 金鑰。金鑰用於瀏覽器連線雲端。金鑰亦屬機密。

第三項是存取碼。存取碼用於控制頁與看板登入測試環境。

另需一台電腦。電腦需可開瀏覽器。另需一台機上盒。機上盒需可開瀏覽器。

## 在電腦開控制頁

1. 開啟控制頁網址：https://ultronservice.github.io/milksha-demo/controller/

2. 在「連線方式」選「雲端模式（店內／機上盒）」。

3. 點開「進階設定」。

4. 在「雲端設定」填入 Firebase 專案 ID。

5. 在「雲端設定」填入 Web API 金鑰。

6. 在「函式區域」填入 asia-east1。若後端另有指示，改填後端提供的區域。

7. 在「測試用存取碼」欄位輸入存取碼。存取碼僅保存在本機瀏覽器。

8. 選擇門市。

9. 按「連線」。

叫號若未成功，控制頁上方會顯示原因。請依文字修正設定或聯絡後端。

## 在機上盒開看板（簡易網址）

機上盒可先記住下列看板網址。門市代碼 s120030 請改為你的門市代碼。

10. 在機上盒瀏覽器開啟：https://ultronservice.github.io/milksha-demo/receiver-demo/?store=s120030&mode=cloud

若看板尚未完成雲端設定，螢幕會顯示說明文字。請改做下一節的設定步驟。

## 在機上盒完成雲端設定

存取碼與金鑰不可手打長字串。請用控制頁產生的設定連結或 QR 碼。

11. 在控制頁按「產生看板連結」。

12. 用機上盒掃描控制頁上的 QR 碼。或在機上盒開啟「看板設定連結」欄位中的網址。

13. 看板會把雲端設定存入機上盒本機。網址列中的設定參數會自動清除。

看板裝置編號預設為 stb-01。若店內有多台機上盒，請在控制頁「進階設定」修改看板裝置編號。並在看板網址加上 device 參數與新編號。格式為在網址末尾加 &device=新編號。

## 確認是否連上

14. 在控制頁按「新增訂單並送出」。

15. 看機上盒看板是否出現該號碼。

16. 在控制頁查看狀態。看板有心跳時，狀態顯示在線。
