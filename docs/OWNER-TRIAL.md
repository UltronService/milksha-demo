# 負責人試用步驟（雲端模式）

## 試用前請準備

1. 向後端索取 Firebase 專案 ID。
2. 向後端索取 Firebase Web API 金鑰（此金鑰可出現在瀏覽器，屬公開設定）。
3. 向後端索取測試用存取碼（僅供控制端連線使用）。
4. 準備一台可開瀏覽器的電腦。
5. 準備一台已安裝 Ultron APK 的機上盒。

## 在電腦開控制端

6. 開啟控制端網址：https://ultronservice.github.io/milksha-demo/controller/
7. 在「連線方式」選「雲端模式（店內／機上盒）」。
8. 點開「進階設定」。
9. 在「Firebase 專案 ID」填入專案 ID。
10. 在「Web API 金鑰」填入 Web API 金鑰。
11. 在「函式區域」填入 asia-east1。
12. 在「測試用存取碼」填入存取碼。
13. 在「選擇門市」選你的門市。
14. 按「連線」。

## 機上盒看板

15. 請 Android 工程師幫機上盒裝好看板設定。
16. 確認機上盒看板已開啟並顯示門市叫號畫面。

## 送出叫號

17. 在控制端「進階設定」輸入「測試環境專用 POS 金鑰」。
18. 在「2. 模擬 POS」輸入號碼與狀態。
19. 按「新增訂單並送出」。
20. 看機上盒看板是否出現該號碼。
21. 在控制端確認狀態為在線。

## 工程人員
